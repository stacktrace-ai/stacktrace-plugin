# 0.6.1 — Turn-end rules run

Custom rules that judge the agent's reply now run in Claude Code and Codex.
A slow policy decision no longer lets a call through.

## Highlights

- **Turn-end rules run** (stacktrace ADR-0232). Claude Code and Codex now
  send each finished turn to the daemon through a `Stop` hook. Before, a
  custom rule on the agent's reply never ran.
- **A slow policy decision does not let a call through.** The hooks for tool
  calls, prompts and finished turns now wait 40 seconds. The CLI waits up to
  25 seconds for a policy engine decision. Before, the hook stopped after 5
  seconds and the call continued.

## Install

```text
/plugin marketplace add stacktrace-ai/stacktrace-plugin
/plugin install stacktrace@stacktrace
```

Existing installations update with `claude plugin update stacktrace@stacktrace`
or with marketplace auto-update. Restart Claude Code to apply the update.

## Compatibility

- Requires `stacktrace-cli` 0.29.0 or newer.
- Requires Claude Code 2.1.274 or newer.
- Turn-end rules need `stacktrace-cli` 0.25.0 or newer. An older CLI lets
  the turn end.
