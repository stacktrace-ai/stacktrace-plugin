# 0.4.1 — Session start runs the same on every host and logs its failures

Claude Code, Codex, Cursor and Devin now run one session start script. A
session start that fails now leaves one line that names the host and the step.

## Highlights

- **One session start script on every host** (ADR-0013). Before, only Claude
  Code ran the session start script. Codex, Cursor and Devin ran the
  registration alone, with no time limit and no diagnosis. Now every host runs
  `scripts/session_start.sh` with its agent kind. The script registers the
  session under a 5-second limit, then checks the CLI and the daemon socket.
- **Session start failures are logged.** Each failure adds one line to
  `session-start.log` in the Stacktrace state directory: the time, the agent
  kind, the step and a fixed reason. Examples are a missing CLI, a CLI that is
  too old, a registration timeout and an unreachable daemon. A healthy session
  writes nothing. `stacktrace-cli` 0.19.1 writes its own failures to the same
  file.
- **Codex shows session start warnings.** Codex now shows a warning when the
  CLI or the daemon is missing. Cursor and Devin show nothing, because their
  hook documentation does not say that such a message is shown.

## Install

Claude Code:

```text
/plugin marketplace add stacktrace-ai/stacktrace-plugin
/plugin install stacktrace@stacktrace
```

Existing installations update with `claude plugin update stacktrace@stacktrace`
or with marketplace auto-update. Restart Claude Code to apply the update.

Cursor CLI:

```text
agent plugin marketplace add github.com/stacktrace-ai/stacktrace-plugin --git-ref v0.4.1
```

Codex CLI: follow the "Codex CLI policy hooks" section of the README.

Devin: follow the "Devin policy hooks" section of the README, with the tag
`v0.4.1`.

## Compatibility

- The `stacktrace-cli` and Claude Code minimums are the same as in 0.4.0.
- **Claude Code registration fails with `stacktrace-cli` 0.13.x.** The script
  now passes `--agent-kind`, which the CLI accepts from 0.14.0. The log records
  the failure as `register-exit 2`. Upgrade the CLI.
- **Codex, Cursor and Devin can wait up to 5 seconds** for the daemon socket
  at session start, as Claude Code already does. The Codex hook time limit
  goes from 5 to 15 seconds.
