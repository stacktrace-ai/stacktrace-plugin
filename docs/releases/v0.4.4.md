# 0.4.4 — Claude Cowork tasks

An organization Owner can now build a Stacktrace zip for Claude Cowork. Each
Cowork task then installs the CLI, connects to Fleet and applies the
organization's policy. The plugin for Claude Code, Codex, Cursor and Devin
does not change.

## Highlights

- **Claude Cowork** (ADR-0014). Cowork runs each task in a new cloud VM and
  has no setup script, so the Owner uploads a plugin zip and marks it
  Required. One command builds the zip with the organization's Fleet token:
  see the "Claude Cowork" section of the README. In each task, the zip's
  hooks install `stacktrace-cli` 0.27.0, save the token and start the
  daemon. A hook that decides waits until the daemon holds the policy, so
  the first prompt of a task is checked. In live tests, a prompt with a
  secret, a write of a key and a `curl` that sends a key were blocked. Fleet
  names each finding "Claude Cowork", with the person.
- **Fast after a VM restart.** Cowork restarts the VM during a task, and the
  daemon stops with it. The next deciding hook waits about 2 to 3 seconds,
  and the first prompt of a new task about 8 seconds.

## Install

Claude Code:

```text
/plugin marketplace add stacktrace-ai/stacktrace-plugin
/plugin install stacktrace@stacktrace
```

Existing installations update with `claude plugin update stacktrace@stacktrace`
or with marketplace auto-update. Restart Claude Code to apply the update.

Cursor CLI:

```text
agent plugin marketplace add github.com/stacktrace-ai/stacktrace-plugin --git-ref v0.4.4
```

Claude Cowork: an Owner runs the command in the README's "Claude Cowork"
section, then uploads `~/Downloads/stacktrace-cowork.zip` in the organization
settings and sets it to Required.

## Compatibility

- **Cowork needs a Team or Enterprise plan and `stacktrace-cli` 0.27.0**,
  which the zip installs. Organization settings > Capabilities > Code
  execution must keep network egress on and allow `api.stacktrace.ai` and
  `stacktrace.ai`. If not, the task continues without checks, and session
  start shows one line that names the setting.
- **Build and upload a new zip after each plugin release**, and when you
  rotate the token. A zip keeps the plugin version it was built from.
- **The zip holds an organization Fleet token.** Use a token for Cowork
  only. Rotate it when a member who had the zip leaves.
- In Cowork, `stacktrace-secret-path-read` and `stacktrace-persistence-planted`
  detect and report, but Fleet cannot block them yet.
- The plugin for Claude Code, Codex, Cursor and Devin is the same as in
  0.4.3. The `stacktrace-cli` and Claude Code minimums are the same as in
  0.4.3.
