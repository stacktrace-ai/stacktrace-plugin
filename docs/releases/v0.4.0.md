# 0.4.0 — Built-in tools, prompts and Devin reach Fleet policy

Fleet policy now reaches the built-in tools and the prompts of Claude Code.
A Block on a detection rule stops a shell command, a file write or a prompt
before it runs. The plugin also ships hooks for Devin.

## Highlights

- **Claude Code sends built-in tools to Fleet policy.** The `PreToolUse` hook
  now also covers `Bash`, `Monitor`, `Write`, `Edit`, `MultiEdit`,
  `NotebookEdit`, `WebFetch` and `WebSearch`. A detection rule with a Block
  entry stops such a call before it runs. Examples are a credential sent out by
  `curl`, a recursive delete of the folder that holds the workspace, and a key
  written to a file. Read-only tools, such as `Read` and `Grep`, do not run the
  hook. The hook also receives `PowerShell`, the shell tool of Claude Code on
  Windows. `stacktrace-cli` 0.19.0 does not classify `PowerShell` yet, so it
  gives such a call no decision, and the call runs.
- **Claude Code sends prompts to Fleet policy.** A new `UserPromptSubmit` hook
  lets a Block on credentials in prompts or personal data in prompts stop the
  prompt before the model reads it.
- **Fleet policy in Devin.** The plugin has a `devin` folder with Devin hooks
  (ADR-0012). `SessionStart` registers the project, and `PreToolUse` asks the
  daemon about each MCP call. Fleet's MCP default decides each call. The hooks
  run in local Devin sessions only: the CLI and Devin Desktop. Install the
  folder from a release tag, as the README describes.

## Install

Claude Code:

```text
/plugin marketplace add stacktrace-ai/stacktrace-plugin
/plugin install stacktrace@stacktrace
```

Existing installations update with `claude plugin update stacktrace@stacktrace`
or with marketplace auto-update. Restart Claude Code to apply the update.

Cursor CLI:

```text
agent plugin marketplace add github.com/stacktrace-ai/stacktrace-plugin --git-ref v0.4.0
```

Codex CLI: follow the "Codex CLI policy hooks" section of the README.

Devin: follow the "Devin policy hooks" section of the README, with the tag
`v0.4.0`.

## Compatibility

- Requires `stacktrace-cli` 0.5.2 or newer for Claude Code.
- Requires `stacktrace-cli` 0.19.0 or newer for built-in tool and prompt
  decisions in Claude Code, and for the Devin hooks. An older CLI may give no
  decision, and then the call or the prompt continues.
- Requires `stacktrace-cli` 0.17.0 or newer for the Cursor and Codex policy
  hooks.
- Requires Claude Code 2.1.274 or newer for policy admission hooks.
- **More calls run the hook.** Each built-in tool call above and each prompt
  now runs `stacktrace remote policy hooks admit`. For these, the CLI sends the
  call's input or the prompt text to the local daemon. That text does not go
  to Fleet. Only the finding of a block does.
- Devin CLI 3000.11.92 or newer sets `PLUGIN_ROOT` for plugin hooks. No
  signed-in Devin session has run this plugin yet.
