# 0.5.0 — Local Cowork tasks, Cursor built-in calls, Pi and OpenCode

Stacktrace now checks Claude Cowork tasks that run on the person's Mac. Fleet
policy now applies to Cursor's shell commands, writes, deletes and reads. Pi
and OpenCode can install the plugin's policy hook.

## Highlights

- **Local Claude Cowork tasks** (ADR-0015). A local Cowork task runs Claude
  Code on the person's Mac. Its hooks use the CLI that the Stacktrace
  installer or MDM put on the Mac, and the zip installs nothing there. Fleet
  names each finding "Claude Cowork". With the MDM key
  `requireCoworkFullVmSandbox`, Claude Code runs in the VM on the Mac, and
  the zip sets up that VM as it sets up a cloud task. We did not test that
  setting in the desktop app.
- **Cowork installs `stacktrace-cli` 0.28.0.** The zip's hooks install
  0.28.0 in each cloud task. That release also stops a blocked prompt from
  marking an earlier, allowed send of the same text as blocked.
- **Cursor built-in calls** (ADR-0016). The Cursor hooks file now sends
  `Shell`, `Write`, `Delete` and `Read` calls to the policy hook. In live
  tests, a write of a token, a `curl` that sends a token and a piped install
  script were denied in the Cursor CLI. Before, only MCP calls and prompts
  went to the hook.
- **Pi and OpenCode.** This repository is now a Pi package that loads only
  the Stacktrace extension:
  `pi install git:github.com/stacktrace-ai/stacktrace-plugin@v0.5.0`.
  For OpenCode, clone the tag and add `opencode/stacktrace.ts` to the
  `"plugin"` list in `opencode.json`. Each blocks tool calls, MCP calls and
  messages that Fleet policy blocks. See "Pi policy hooks" and "OpenCode
  policy hooks" in the README.

## Install

Claude Code:

```text
/plugin marketplace add stacktrace-ai/stacktrace-plugin
/plugin install stacktrace@stacktrace
```

Existing installations update with `claude plugin update stacktrace@stacktrace`
or with marketplace auto-update. Restart Claude Code to apply the update.

Cursor CLI:

```text
agent plugin marketplace add github.com/stacktrace-ai/stacktrace-plugin --git-ref v0.5.0
```

Claude Cowork: an Owner runs the command in the README's "Claude Cowork"
section, then uploads `~/Downloads/stacktrace-cowork.zip` in the organization
settings and sets it to Required. Local tasks also need Stacktrace on each
Mac, connected to Fleet.

## Compatibility

- **Build and upload a new Cowork zip.** A zip keeps the plugin version it
  was built from, so an old zip still installs `stacktrace-cli` 0.27.0.
- **Local Cowork tasks, Pi and OpenCode need `stacktrace-cli` 0.28.0** or
  newer on the computer. With an older CLI, a local Cowork task shows as
  Claude Code, and Pi's and OpenCode's checks fail open, so the call runs.
- **Cursor's `Shell`, `Write` and `Delete` calls need `stacktrace-cli`
  0.22.0** or newer. A Cursor `Read` is checked only by a `stacktrace-cli`
  newer than 0.28.0. 0.28.0 reads no action from it, and the read runs.
- The minimums for the rest of the plugin do not change: `stacktrace-cli`
  0.5.2 or newer, and Claude Code 2.1.274 or newer for the policy hooks.
