# 0.6.0 — Codex injection blocks and Devin built-in calls

Fleet's Block for an injected instruction now stops a Codex call before it
runs. Fleet's Block now stops Devin's shell commands, file reads, writes and
edits, searches and web calls. Claude Cowork tasks install `stacktrace-cli`
0.29.0. Both new hooks need `stacktrace-cli` 0.29.0 or newer.

## Highlights

- **Codex injection blocks** (stacktrace ADR-0281). A new Codex `PostToolUse`
  hook sends each MCP and `Bash` result to the daemon, as the Claude Code
  hooks do. A later call that carries out an instruction from such a result
  then reaches `stacktrace-injection-followed` before it runs, so Fleet's
  Block stops it. Before, the finding came only after the call.
- **Devin built-in calls** (stacktrace ADR-0285). Devin's `PreToolUse` hook
  now also runs for `exec`, `read`, `write`, `edit`, `apply_patch`,
  `notebook_read`, `notebook_edit`, `grep`, `glob`, `find_file_by_name`,
  `code_search`, `webfetch` and `web_search`. A Block entry stops a call that
  its rule finds. Before, Devin's hook ran only for MCP calls and prompts. On
  2026-11-25, live suite runs on Devin CLI 3000.14.30821 blocked a token sent
  with `curl`, a token written to a file, a delete of a home folder, a `.env`
  read, a planted git alias, an unknown package install and a sent IBAN.
  `write_to_process` also reaches the hook, but no rule reads it yet.
- **Claude Cowork installs `stacktrace-cli` 0.29.0.** The zip's hooks install
  0.29.0 in each cloud task. That release adds the branded hook notices and
  the session context for the policy engine's judge.

## Install

Claude Code:

```text
/plugin marketplace add stacktrace-ai/stacktrace-plugin
/plugin install stacktrace@stacktrace
```

Existing installations update with `claude plugin update stacktrace@stacktrace`
or with marketplace auto-update. Restart Claude Code to apply the update.
`stacktrace setup` from `stacktrace-cli` 0.29.0 installs or updates the plugin
for Claude Code and Codex, and for Devin when Devin is signed in.

Cursor CLI:

```text
agent plugin marketplace add github.com/stacktrace-ai/stacktrace-plugin --git-ref v0.6.0
```

Claude Cowork: an Owner runs the command in the README's "Claude Cowork"
section, then uploads `~/Downloads/stacktrace-cowork.zip` in the organization
settings and sets it to Required.

## Compatibility

- **Upgrade `stacktrace-cli` to 0.29.0 before this plugin.** With an older
  CLI, Codex's `PostToolUse` hook sends nothing, and Devin's built-in calls get
  no decision, so each call runs as before.
- **Codex asks again.** The new `PostToolUse` hook changes the plugin's hooks,
  so Codex asks you to approve them again.
- **Build and upload a new Cowork zip.** A zip keeps the plugin version it was
  built from, so an old zip still installs `stacktrace-cli` 0.28.0.
- The minimums for the rest of the plugin do not change: `stacktrace-cli`
  0.5.2 or newer, and Claude Code 2.1.274 or newer for the policy hooks.
